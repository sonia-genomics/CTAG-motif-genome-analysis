# FIGURES AND VISUALIZATIONS

The project generates multiple publication-style figures.

---

# Figure Categories

## Comparative Analysis

- Boxplots
- Violin plots
- Distribution plots

---

## Clustering Analysis

- PCA plots
- Hierarchical dendrograms

---

## Heatmaps

- Tetranucleotide abundance heatmaps
- CTAG suppression maps

---

## Local Genomic Analysis

- CTAG density tracks
- Genome browser tracks
- Hotspot visualization

---

## Statistical Plots

- Correlation plots
- Entropy analysis
- GC relationship analysis

---

# Visualization Goals

The visualizations aim to:

- Reveal motif patterns
- Identify clustering behavior
- Compare bacterial genomes
- Support biological interpretation
