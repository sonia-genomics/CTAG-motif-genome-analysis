# LIMITATIONS

Although the project provides extensive computational analysis,
several limitations remain.

---

# Dataset Size

The study uses a limited number of bacterial genomes.

Larger datasets may improve:

- Statistical power
- Evolutionary interpretation
- Species diversity analysis

---

# Experimental Validation

The project is computational in nature.

Experimental validation is required to confirm:

- Functional significance
- Regulatory activity
- Structural implications

---

# Annotation Quality

Genome annotations may vary in quality across species.

This can influence:

- Gene mapping
- Functional enrichment
- Hotspot interpretation

---

# Biological Complexity

CTAG suppression likely results from multiple interacting factors.

The project cannot fully isolate contributions from:

- Mutation pressure
- Repair systems
- Natural selection
- Structural constraints

---

# Future Improvements

Potential improvements include:

- Larger genome collections
- Long-read sequencing analysis
- Machine learning models
- Experimental genomics
