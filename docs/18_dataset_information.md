# DATASET INFORMATION

The project analyzes publicly available bacterial genomes.

---

# Data Sources

Genomic datasets may include sequences from:

- NCBI GenBank
- RefSeq
- Public bacterial genome repositories

---

# Genome Types

Analyzed datasets include:

- Gram-positive bacteria
- Gram-negative bacteria
- Diverse phylogenetic groups

---

# Sequence Processing

Downloaded files include:

- FASTA genomes
- GenBank annotations

---

# Quality Control

QC steps include:

- Genome completeness checks
- Sequence filtering
- File validation
- Annotation consistency

---

# Metadata

Metadata includes:

- Species name
- Genome size
- GC content
- Taxonomic classification
