# PIPELINE OVERVIEW

The CTAG analysis workflow is implemented using:

- Python
- Biopython
- Pandas
- NumPy
- SciPy
- Scikit-learn
- Matplotlib
- Snakemake

# Pipeline Stages

1. Genome Download
2. Quality Control
3. Gene Extraction
4. Termination Site Analysis
5. O/E Tetranucleotide Analysis
6. Trinucleotide Analysis
7. Statistical Analysis
8. Heatmaps
9. PCA
10. Clustering
11. Entropy Analysis
12. Functional Enrichment
13. Browser Track Generation
14. Final Automated Reporting
